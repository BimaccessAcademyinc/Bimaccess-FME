# Skills de Remotion

Les dossiers `remotion-*` de ce dossier sont les skills officiels de Remotion (dépôt public `remotion-dev/skills`, commit `4733526`, version 4.0.533, alignée sur le Remotion installé dans les leçons (choix d'Ilyas du 2026-11-27), copiés le 2026-11-27), installés comme le prévoit leur documentation (`npx skills add remotion-dev/skills`). Ce sont les mêmes skills que le plugin Remotion du répertoire de plugins.

Ils ne se modifient pas ici : une mise à jour se fait en recopiant le dépôt. Les règles du projet l'emportent sur eux (grammaire d'animation de la chaîne : jamais de fondu d'opacité, de ressort ni de rebond ; vitesse constante ; une seule mise en évidence) ; voir `chaine/agents/code/skills/narrated-lesson-build/references/remotion-outils.md` de bimaccess-studio.

Version installée dans les leçons Studio : `remotion` et `@remotion/player` 4.0.533, la même que ces skills. Si les leçons montent de version, recopier les skills au commit de la nouvelle version (`git log -- skills/remotion-best-practices/SKILL.md`, champ `version`).
