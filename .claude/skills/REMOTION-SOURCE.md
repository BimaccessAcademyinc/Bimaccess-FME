# Skills de Remotion

Les dossiers `remotion-*` de ce dossier sont les skills officiels de Remotion (dépôt public `remotion-dev/skills`, commit `a3f4098`, copiés le 2026-11-27), installés comme le prévoit leur documentation (`npx skills add remotion-dev/skills`). Ce sont les mêmes skills que le plugin Remotion du répertoire de plugins.

Ils ne se modifient pas ici : une mise à jour se fait en recopiant le dépôt. Les règles du projet l'emportent sur eux (grammaire d'animation de la chaîne : jamais de fondu d'opacité, de ressort ni de rebond ; vitesse constante ; une seule mise en évidence) ; voir `chaine/agents/code/skills/narrated-lesson-build/references/remotion-outils.md` de bimaccess-studio.

Version installée dans les leçons Studio : `remotion` et `@remotion/player` 4.0.533 ; un exemple d'un skill peut employer une API plus récente : vérifier qu'elle existe avant de s'en servir.
